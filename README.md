# dsh-cache-workspace

给 [DeepSeek Harness](https://github.com/deepseek-ai) 桌面客户端加一个**缓存工作区**开关：让 agent 把中间产物（截图、下载、转码文件、临时脚本）写进你指定的文件夹，而不是堆在项目根目录；用完之后一键从独立进程里清掉。

安装后出现在输入框工具栏，「电脑操作」的右边：

```
电脑操作 ·  │  📁 .dsh-cache ▾  🧹
```

## 能做什么

- **看**：控件上显示当前缓存文件夹名，每个工作区（会话所在的目录）各自记住自己的选择。
- **选**：点名字打开 Windows 资源管理器挑目录；点右侧箭头从工作区已有目录里选，或新建一个。
- **清**：点 🧹 确认后删除该缓存目录。删除在独立进程里做，即使当前对话被归档、客户端关掉，删除也会完成。
- **教**：插件会往 agent 的系统提示里加一段规则，让它知道这个目录可以随便读写、要用就按工作名建子文件夹、别把东西堆在根目录、用完提醒你可以清理。

## 安装

前提：Windows 上的 DeepSeek Harness 桌面版，且能执行插件命令。

1. 把这个目录放到任意位置（建议留在工作区里，方便一起备份）。
2. 在 DSH 里执行：

   ```
   plugin_manager action=install_bundle target=<本目录的绝对路径>
   ```

   或用 CLI：

   ```
   dsh plugin --profile desktop add "file:<本目录的绝对路径>"
   ```

3. 重启 DeepSeek Harness（或在插件列表里把它禁一次再开）。
4. 输入框工具栏出现 📁 控件就算装好了。

卸载：`dsh plugin --profile desktop remove @local/dsh-cache-workspace`。

## 使用

**选缓存目录**

- 点控件上的 📁 名字 → 打开资源管理器，选一个文件夹。
- 点名字右边的 ▾ → 从当前工作区的子目录里挑，或选「＋ 新建文件夹…」输入名字。
- 选中后 agent 的系统提示会立刻更新成新路径。

**默认位置**

不选的话用 `<当前工作区>/.dsh-cache`。这个目录在沙箱可写范围内，agent 的文件工具和命令工具都能直接用。

**清理**

点 🧹 → 确认 → 目录被递归删除。控件在目录不存在时是灰的。

**agent 会看到什么**

每轮对话开始时，agent 的系统提示里会多出一段「缓存工作区」，写明：

1. 这个目录可以任意创建、读取、执行文件；
2. 不要直接在根目录堆文件，按工作名建子文件夹再用；
3. 缓存目录不是长期存储，随时可能被清理；
4. 用过之后要提醒用户「现在可以点 🧹 清理」；
5. 工作区以外的路径仍然受沙箱限制。

## 缓存目录放在工作区外

可以。选工作区外的目录（比如 `D:\my-cache`）时，插件会做两件事：

1. 建好目录；
2. 给这个目录授予 DSH 沙箱所需的写权限，这样 agent 的 shell 和文件工具才写得进去。

只改你主动选中的那一个目录，不选就不动任何权限。目录必须**属于你当前登录的 Windows 账户**，否则授权会失败，控件上会显示原因。

## 数据与日志

都放在 `%USERPROFILE%\.dsh\dsh-cache-workspace\`：

| 文件 | 内容 |
|---|---|
| `state.json` | 每个工作区选中的缓存目录、授权过的外部目录 |
| `log.txt` | 运行日志（UTF-8），排查问题看这里 |
| `grant.ps1` | 给外部目录授权时生成的临时脚本 |

删掉整个目录等于重置所有选择，不影响已存在的缓存文件夹。

## 已知限制

- 仅支持 Windows。
- 清理是**递归删除**，没有回收站，删了就没了。
- 工作区外的目录若被其他账户或系统占用，授权会失败。
- 控件只记住「工作区 → 缓存目录」的对应关系，不跨机器同步。

## 安全

- 不联网，不上传任何东西。
- 会修改你选中的工作区外目录的访问权限（仅该目录），用于让沙箱里的 agent 能写。
- 清理按钮执行前一定弹确认框。
